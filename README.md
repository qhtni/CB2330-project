### **Project CB2330**  - 🪸 *Coral bleaching generalized linear mixed model: replacing calendar time with climate* 🪸

In the article *Spatial and temporal patterns of mass bleaching of corals in the Anthropocene* by Hughes et al. (2018) predictions about the severity of coral bleaching were made by using GLMM models. The authors suggested that severe coral bleaching increased with calendar time. 

The aim of this project is to use the authors suggested model and compare it to a model where calendar time is replaced by global temperature anomaly.
