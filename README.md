### **Project CB2330**  - 🪸 *Coral bleaching generalized linear mixed model: replacing calendar time with climate* 🪸

In the article *Spatial and temporal patterns of mass bleaching of corals in the Anthropocene* by Hughes et al. (2018) predictions about the severity of coral bleaching were made by using generalized linear mixed models (GLMMs). The authors' suggested that severe coral bleaching increased with calendar time. 

The aim of this project is to use model suggested by the authors and compare it to a new model where calendar time is replaced global temperature anomaly.
