# Data

File that is necessary for colab notebook:

**The csv file "master_location_year.csv" :** the output from the R notebook (combines official climate data we found online and the researcher's bleaching data)

Files necessary for the R notebook (no need to actually run the notebook - subsequently no need to download these files either):

**The excel file "coral_data.xlsx" :** Table from the paper describing the severity of bleached coral reefs at four different regions, containing specific locations from 1980 to 2016.

**The csv file "dataset_enso_2026.csv" :** Online data from https://www.kaggle.com/datasets/shabanamir/enso-data. ENSO-related climate data from 1950–2026, sourced from NOAA (National Oceanic and Atmospheric Administration). All variables are described there too.
